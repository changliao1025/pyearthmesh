Welcome to PyEarthMesh documentation!
=====================================

.. note::
   PyEarthMesh is part of the **PyEarthSuite** ecosystem.
   To keep each package lightweight and focused, functionality is split across specialized packages:

   - **pyearth** - Core GIS operations, spatial toolbox, and system utilities
   - **pyearthviz** - 2D visualization with Matplotlib and Cartopy
   - **pyearthviz3d** - 3D globe visualization with GeoVista
   - **pyearthriver** - River network topology and graph algorithms
   - **pyearthmesh** (this package) - Mesh generation and spatial modeling toolkit
   - **pyearthhelp** - Data retrieval and HPC utilities
